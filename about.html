About Study Helper

项目概述 / Overview

Study Helper 是一款面向国际高中生、AP考生、托福/雅思/SAT备考学生的校园互助学习平台。该平台旨在解决大部分学生遇到难题时，因害羞、自卑、碍于情面，不敢直接向老师或同学提问的问题。本平台致力于打造一个低压力、高隐私、简约通透的校内学习社区，让提问不再尴尬，让互助更加简单高效。

核心功能 / Core Features

  1. 多元化发帖求助与招募系统：学生可以自由选择匿名 / 实名两种模式发布学习提问、难题求助、学习搭子招募。发布内容时，用户可自主设置任务截止时间、悬赏报酬，并添加对应学科标签，例如AP计算机、AP微积分、托福口语、AP心理等，方便其他学生精准检索与作答。
  2. 师生双端适配作业管理系统：平台同时支持学生账号与教师账号。教师可发布每日课后作业、同步练习、考试试卷以及各类学习资料；学生能够随时查看全部待完成作业，清晰规划学习任务。系统支持作业自主勾选完成功能，帮助学生告别遗忘作业、学习混乱的问题，所有共享资料免费下载。
  3. 校园公告与赛事发布：依托校内专属School Board板块，任课教师可独立发布校园官方通知、近期重要日程、学科竞赛资讯、赛事报名通道及配套备考资料。让学生第一时间掌握校内动态、截止日期与竞赛信息，一站式整合全部校园学习内容。
  4. 标签+关键词双重检索：平台内置完整分类标签库，覆盖全品类AP学科与主流出国类考试。用户可通过标签筛选帖子、作业、资料，也可直接关键词搜索，快速定位需要的学习内容。
  5. 二元身份权限划分：平台分为学生账号、任课教师账号两类权限，各自拥有专属操作权限，适配教学答疑、互助发帖、资源分享等校园场景，结构简洁，轻量化易管理。
  6. 全方位隐私安全与举报监管：匿名模式隐藏全部个人信息，保护学生隐私，禁止网暴与辱骂。平台内置智能举报系统，用户可举报违规内容；单条帖子举报累计达到5次，系统自动下架，维护干净友好的学习社区。

项目价值 / Project Value

Study Helper 打破传统学习的社交壁垒，弱化提问羞耻感，兼顾学生与老师的使用需求。集合发帖互助、作业管理、公告赛事、资源共享、社区监管于一体，打造专属于国际学校学生，简约舒适、低压力的一站式学习社区。
